# Forest FirePrevention via Simulation and Computer Vision

**Bachelor's Capstone Thesis Project in Computer Science**

This project investigates the use of **computer vision and machine learning for early forest fire detection**, combining a **Unity-based forest simulation** with **real-world video data** to create and evaluate datasets for fire detection.

## Overview

The project focuses on:

- Creating a simulated forest environment using Unity
- Generating fire and smoke scenarios
- Creating a synthetic image dataset
- Building a real-world dataset from video footage
- Training computer vision and CNN-based models
- Evaluating and comparing model performance
- Identifying effective approaches for forest fire detection
